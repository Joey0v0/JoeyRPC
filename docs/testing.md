# 测试与验证

测试与被测代码放在同一目录，文件名以 `_test.go` 结尾。普通 `go build` 和使用方导入库时不会编译这些文件；只有 `go test` 会编译运行测试。

## 常用命令

```sh
go test -count=1 ./...
go vet ./...
```

`-count=1` 禁用测试结果缓存，`./...` 覆盖根包、子包及示例程序的构建。

需要采集固定载荷和并发条件下的吞吐、延迟及故障数据时，运行 [`benchmarks/`](../benchmarks/)；测试条件与本地结果见[基准报告](benchmark.md)。

支持 CGO 且已配置 C 编译器的环境可以运行：

```sh
go test -race ./...
```

## 测试范围

| 范围 | 验证内容 |
| --- | --- |
| 单连接通信 | TCP、HTTP CONNECT、并发和异步调用、Seq 响应匹配、业务错误后继续调用 |
| 编解码与方法注册 | Gob 消息完整性、新旧消息头字段兼容、反射签名、指针参数、map/slice 结果 |
| 生命周期 | 调用取消与响应解码竞争、处理超时、连接初始化取消、迟到构造器释放 |
| 注册与发现 | 心跳、记录过期、HTTP 状态、随机/轮询、共享刷新、显式更新与刷新竞争 |
| 多节点客户端 | 同节点共享建连、不同节点独立建连、关闭与建连竞争、广播 |
| Metadata 与拦截器 | 请求隔离、map 快照、执行顺序、鉴权阻止执行、替换参数 |
| 重试 | 建连失败后切换节点、业务错误不重试、幂等标记、次数上限、退避期间取消 |
| 优雅关闭 | 拒绝新 RPC、已有响应收尾、统计处理超时后仍运行的方法、关闭超时与取消、等待响应写入 |

## 示例验证

两个终端分别运行：

```sh
go run ./examples/basic/server
go run ./examples/basic/client -a 10 -b 20
```

预期客户端输出 `10 + 20 = 30`，服务端按 Ctrl+C 后收尾。

其他示例：

```sh
go run ./examples/registry
go run ./examples/features
```

注册中心示例中部分休眠调用预期超时；扩展功能示例中缺少 token 的调用预期返回 `unauthorized`。这些是示例主动验证的错误分支。

## 验证环境与边界

本轮本地验证环境为 Go 1.26.4、Windows/amd64。全量测试与 `go vet` 通过，扩展功能相关测试重复运行 20 次通过，注册中心和扩展功能示例运行通过。

当前环境关闭 CGO，未运行竞态检测；Unix Socket 测试仅在 Linux 上运行，在 Windows 上跳过。`go.mod` 保留原来的 Go 1.13 声明，最低版本兼容性未单独验证。

这些检查验证当前实现的功能与已覆盖的并发边界，生产负载、长期运行和其他网络故障场景尚待验证。
